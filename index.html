About me

A BSIT student who likes finding what breaks before users do.

I'm a 3rd year BSIT student at the Polytechnic University of the Philippines, Sto. Tomas. My interest in QA started with academic projects, where I kept asking what happens if the user does this instead. That curiosity became a habit of writing test cases and documenting defects clearly.

Testing philosophy: a good bug report saves a developer an hour. I write tests that are reproducible, specific, and tied to a requirement, and I report defects so anyone on the team can verify them.

Automation

A Playwright check that automates the validation bug logged as BUG-LKL-042.

// tests/booking-validation.spec.js
const { test, expect } = require('@playwright/test');

test('rejects check-out before check-in', async ({ page }) => {
  await page.goto('http://localhost/lakbaylokal/hotels/1');
  await page.getByLabel('Check-in').fill('2026-12-20');
  await page.getByLabel('Check-out').fill('2026-12-18');
  await page.getByRole('button', { name: 'Book now' }).click();

  await expect(page.getByText('Check-out must be after check-in')).toBeVisible();
});
